This is the question we answer most, and the honest answer is that it depends on *what's wrong*, not just how old the machine is. Some five-year-old machines are worth keeping; some three-year-old ones aren't.

## Lean toward repair when

- **The problem is software.** Slowness, clutter, pop-ups, a Windows installation that's gone strange — these are cleanup problems, not hardware problems. A [Dave Perfect](/dave-perfect/) pass on a sound machine routinely buys years.
- **It's one inexpensive part.** A failed hard drive replaced with an SSD, more memory, a new power supply. If the rest of the machine is healthy, a single-part fix is usually the right money.
- **The machine runs something that's hard to move.** Specialized equipment, old-but-critical software, a license tied to the hardware. Sometimes keeping a machine alive is genuinely the cheapest option, done with eyes open and a backup plan.

## Lean toward replace when

- **The motherboard or processor has failed.** Repair cost approaches replacement cost, on old parts.
- **It can't run a supported version of Windows.** A machine that can't receive security updates doesn't belong on a business network, whatever else is true of it.
- **It's the second significant failure.** Machines that have started failing tend to continue.
- **The time cost is adding up.** If someone reboots twice a day and waits ten minutes every morning, the machine is charging you rent in staff time. That cost is real even though it never shows up on an invoice.
- **Laptop batteries, hinges, and screens on older consumer models** — individually repairable, rarely worth it in combination.

## The rule of thumb

If the repair costs more than half of what a suitable replacement costs, replace. If the machine is past five years and the failure is anything structural, replace. Otherwise, repair — and put the difference toward doing the replacement properly when the time actually comes.

When you do replace, the transition matters more than the hardware: files, settings, and software moved completely, and the new machine set up clean. That's covered in [what we need from you before we set up a new machine](/knowledge/new-machine-checklist/).
