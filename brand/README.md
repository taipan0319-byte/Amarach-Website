# Amárach Net Solutions — brand files

All type is converted to outlines. Nothing here depends on a font being installed,
so a sign shop, a print shop, or an embroidery digitiser can open these directly
without substituting anything.

`/brand/*.svg` — vector masters. Use these for anything printed or physical.
`/brand/png/*.png` — raster previews exported from those same SVG files, so what
you see in the PNG is exactly what the vector produces.

## Files

| File | Use |
|---|---|
| `logo-horizontal` | Default. Website header, letterhead, email signature. |
| `logo-horizontal-reversed` | On navy or any dark background. |
| `logo-horizontal-1c-navy` | Single colour. Fax forms, engraving, anywhere one ink. |
| `logo-stacked` | Square-ish spaces. Van door, sponsor board, invoice header. |
| `logo-stacked-reversed` | Same, on dark. |
| `mark` / `mark-reversed` | The A alone, where the name already appears nearby. |
| `icon-app` | 256px rounded tile. Social avatar, app icon. |
| `icon-favicon` | Browser tab. Export to `.ico` at 32 and 16px. |
| `seal-green` | **Primary Dave Perfect seal.** Outline, on white. |
| `seal-green-solid` | Filled version, for dark backgrounds or more weight. |
| `seal-green-sticker` | The physical sticker: SERVICED, date field, phone. |
| `seal-navy` | Seal in company navy, for letterhead where green would clash. |

## Colours

```
Navy      #1B2A4A   primary, wordmark, headers
Bright    #2A7AC2   the crossbar beam only
Blue      #3D6E9E   links, NET SOLUTIONS
Shirt     #C9DCEF   tints, reversed subtype
Rule      #DBD9D4   hairlines
Seal      #2F6F4E   Dave Perfect seal only — nowhere else
```

Pantone/CMYK equivalents need a printer's eye on a real proof. Don't let a shop
convert these numerically and call it done.

## Rules

- **Clear space:** leave the height of the A on all four sides. More is fine.
- **Minimum width:** horizontal lockup 120px on screen, 1.25in in print. Below
  that, use `mark` or the stacked version.
- **The beam gap.** In the one-colour and outline artwork there is a hairline of
  clear space where the beam crosses the A. It is deliberate. At small sizes ink
  spreads and without it the beam and the letter merge into one blob. Do not
  close it up.
- **Don't** recolour the beam, stretch the lockup, add a shadow or outer glow,
  put the logo on a busy photo, or rebuild the wordmark by typing it in a font.
  Use the file.
- **The seal is for Dave Perfect,** the named service. It is not a general company
  logo and shouldn't be used as one. Keep the ring text intact so it always reads
  as Amárach's own mark — never crop it down to something that could be mistaken
  for a third-party certification or a government endorsement.
